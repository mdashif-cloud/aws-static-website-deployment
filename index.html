// SETUP

How it was deployed

The exact sequence used to take this page from a local HTML file to a live URL.

01
Create S3 bucketPublic access unblocked, versioning enabled so every file change stays recoverable.
02
Upload site filesindex.html and assets uploaded directly to the bucket root.
03
Enable static website hostingBucket property turned on with index.html set as the index document.
04
Attach a public-read bucket policyGrants s3:GetObject to all visitors — without it, every request returns Access Denied.
05
Verify the website endpointThe S3 static website hosting URL is confirmed live and publicly reachable.
06
Next step: CloudFront + HTTPSPlanned once AWS account verification clears, to add a CDN layer and HTTPS support.
